# IDPG Output Directory

This directory contains the manuscript figures generated by the IDPG simulation scripts.

## Directory Structure

```
output/
├── simulations/     # Validation simulations (sim1, sim2, sim6)
└── heat_maps/       # Phase 2 heat map figures (A-E)
```

**Note**: Example outputs have been moved to `archive/example_outputs/` during codebase cleanup.

## Mathematical Background

### IDPG Framework

- **Latent Space**: B^d_+ (non-negative unit ball)
- **Intensity**: rho(g, r) defines site density
- **Connection**: P(i -> j) = g_i . r_j

### Key Formulas

**Node-Centric** (long-lived entities):
- E[|E|] = E[N]^2 * (mu_tilde_G . mu_tilde_R)

**Edge-Centric** (ephemeral interactions):
- E[L] = (E[N]/2) * (mu_tilde_G . mu_tilde_R)

**Bound Heat**:
- h_bar(g,r) = K(g,r) * rho_G(g) * rho_R(r)
